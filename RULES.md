# agentic-postcard rules

These rules bind every run of agentic-postcard. They also bind
agents that drive this pack over MCP.

1. Preview before you act. Run each send with dry run first.
2. Mail live only on request. No key means no live send.
3. Verify every recipient. Refuse live mail to an undeliverable address.
4. Respect guards. A denied call stays denied.
5. Report failures as failures. Adapters throw, and callers surface
   the error. No silent success follows a failed call.
6. Count the cost. Read the cost report before you close a task.
7. Keep quiet hours. The pack refuses sends inside the window.

Pack: Send postcards through print vendors from CLI, code, or MCP. Keywords: postcards, direct-mail, lob, postgrid, agentic-suite, claude-code, codex, cli, mcp.
